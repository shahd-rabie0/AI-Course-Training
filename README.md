Python Practice 2: File Handling & Exception Handling

A practice notebook where I learned:

File handling: opening files, read modes (r, w, a, x), read(), readline(), readlines(), seek(), writing, appending, deleting files
Common exceptions: ImportError, IndexError, NameError, SyntaxError, TypeError, ValueError
Exception handling: try, except, else, finally, and raise
How to run :
Install Python 3 and Jupyter (pip install notebook)
Open Python_2.ipynb
Run all cells from the top (Kernel → Restart & Run All)

The notebook creates the text files it needs, so there is nothing else to download.
